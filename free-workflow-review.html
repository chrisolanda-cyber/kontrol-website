What people ask before booking

Will it work with the software we already use?

Usually, yes. The automation sits between your systems rather than replacing them, so it is designed around what you already run: job management, accounting, email and shared inboxes.

If something has an API or a regular export, it can generally be connected. The review is where that gets checked against your actual systems, before anything is quoted.

What happens in the 60 minutes?

We walk through how work moves through your office today, where the hours go, and which tasks are repetitive enough to automate. No prep needed.

You leave with a short ranked list: which workflow to automate first, roughly what it would save, and which tasks are not worth automating. It runs as a video call, so location doesn't matter.

Will it send things without us checking?

Only if you want it to. Invoices, credits, orders and customer messages can start as drafts that your team approves.

Every run is logged, so any output can be traced back to the email or document that produced it. Once you trust a step, it can be switched to run on its own.

What does a first build cost?

The review is free. A build is a fixed price, agreed in writing before any work starts, and can be a single workflow.

The price comes out of the review, so it is attached to a defined piece of work rather than a guess. Hosting, monitoring and support run as a monthly service. If the review says a process isn't worth automating, that's what you'll be told.
